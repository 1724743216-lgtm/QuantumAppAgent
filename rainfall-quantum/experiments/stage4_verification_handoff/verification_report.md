## 2. 指标对比

### 2.1 核心指标对比表

| 指标 | 经典 LSTM 基线 | 量子混合 VQC+LSTM | 差值 | 说明 |
|------|---------------|---------------------|------|------|
| **RMSE (mm)** | 0.1753 | 0.1787 | +0.0034 | 量子略高（越低越好） |
| **MAE (mm)** | 0.1213 | 0.1239 | +0.0026 | 量子略高（越低越好） |
| **MAPE (%)** | 79.24 | 77.94 | **-1.30** | 量子略优（越低越好） |

### 2.2 训练效率对比

| 指标 | 经典 LSTM 基线 | 量子混合 VQC+LSTM |
|------|---------------|---------------------|
| 训练轮数 (epochs) | 50 | 30 |
| 最佳 epoch | 40 | 28 |
| 批大小 (batch_size) | 64 | 32 |
| 学习率 | 0.001 | 经典部分 0.001 / 量子部分 0.0005 |
| 训练耗时 | 13.7s | 82.5s（约 6x） |
| 总参数量 | ~17K | 52,536（含 30 量子参数） |

### 2.3 指标差异分析

1. **RMSE / MAE**：量子混合模型比经典基线分别高 +0.0034mm 和 +0.0026mm，差异幅度约为基线值的 1.9% 和 2.1%，处于可接受范围内。此差异主要来源于：
   - 模拟器逐样本执行量子电路导致的训练不稳定性
   - 量子变分参数（仅 30 个）在 StatevectorSimulator 上的梯度通过 `.detach()` 传递，无法实现完整的参数梯度穿透
   - 训练轮数较少（30 vs 50 epochs），量子模型可能未充分收敛

2. **MAPE**：量子混合模型在相对误差指标上略优于经典基线（-1.30%），表明量子特征提取对中等-强降雨样本的相对预测精度有轻微改善。

3. **训练耗时**：量子混合模型训练耗时约为经典基线的 6 倍，主要瓶颈在于 VQC 层逐样本执行 StatevectorSimulator，无法利用 GPU 批量并行。

## 3. 局限性说明

### 3.1 数据局限

- **合成数据**：当前使用基于 Z-R 关系 + 噪声 + 季节性模式生成的合成数据，未在真实气象观测数据（如 SEVIR、CIKM 2017）上验证。合成数据的分布特性可能无法完全反映真实降雨的复杂时空相关性。
- **数据规模**：7000 个样本总量较小，可能不足以充分训练量子变分参数。

### 3.2 量子计算局限

- **模拟器执行**：所有量子电路通过 cqlib StatevectorSimulator 在经典计算机上模拟执行，并非真实量子硬件。真实硬件上的噪声、退相干等因素未被考虑。
- **量子比特数限制**：n_qubits=6 受模拟器计算复杂度限制。真实量子硬件可支持更多比特，但当前模拟器规模下无法探索更大量子特征空间。
- **梯度穿透问题**：量子变分参数通过 `.detach().cpu()` 传入电路，梯度无法自动穿透量子模拟器。训练依赖经典部分的梯度回传和量子输出对损失的间接贡献，可能导致量子参数优化效率低于纯经典端到端训练。

### 3.3 性能局限

- **量子模型 RMSE 略劣于经典基线**：当前实验中量子混合模型未超越经典 LSTM 基线。量子特征提取模块在当前配置下未能提供显著性能增益。
- **MAPE 偏高**：两种模型的 MAPE 均接近 80%，说明对弱降雨样本（分母趋近零）的相对误差较大，这在降雨量预测任务中是常见挑战。

### 3.4 工程局限

- **单机部署**：当前为单机 FastAPI 部署，未实现分布式推理和负载均衡。
- **同步训练**：`/api/train` 接口为同步执行，长时间训练会阻塞 HTTP 请求。

## 4. 后续改进方向

### 4.1 短期改进

1. **真实数据验证**：接入 SEVIR 或 CIKM 2017 降雨量数据集，验证模型在真实气象数据上的表现。
2. **增大训练预算**：增加量子混合模型的训练轮数（至 100+ epochs），观察是否进一步提升。
3. **量子电路优化**：尝试更深的变分层（3-4 layers）、更丰富的纠缠模式（环形/全连接），或增加量子比特数。
4. **梯度穿透优化**：探索参数移位法（parameter-shift rule）实现量子层解析梯度，替代当前的 `.detach()` 近似。

### 4.2 中期改进

5. **混合编码策略**：尝试角度编码 + 振幅编码的组合，更充分利用量子态空间。
6. **注意力机制融合**：在 LSTM 编码器和量子层之间引入注意力机制，让量子层聚焦于关键时间步的特征。
7. **真实量子硬件验证**：在 cqlib 支持的真实量子后端上运行，评估噪声对预测精度的影响。
8. **异步训练接口**：将 `/api/train` 改为异步任务，支持训练进度查询。

### 4.3 长期方向

9. **多变量量子编码**：将 7 个气象特征分别编码到不同量子比特子空间，探索量子纠缠与气象变量相关性的关联。
10. **量子-经典联合架构搜索**：自动搜索最优的量子层位置、深度和经典网络组合。

## 5. 验证结论

| 维度 | 结论 |
|------|------|
| **一致性** | 基线报告与量子报告的任务、数据、指标定义完全一致，对比公平 |
| **性能** | 量子混合模型 RMSE 比经典基线高 +0.0034mm（+1.9%），MAPE 低 -1.30%（-1.6%），整体性能与经典基线相当 |
| **可靠性** | 量子模型在模拟器环境下可稳定训练和推理，无崩溃或数值异常 |
| **局限性** | 合成数据、模拟器执行、梯度穿透受限，当前量子模型未超越经典基线 |
| **交付判定** | **通过验证，可交付**。当前结果如实反映了模拟器规模下量子混合方法的实际表现，未夸大量子优势 |

> **重要声明**：本应用中量子混合模型的性能数据基于 cqlib StatevectorSimulator 模拟器获得，不代表真实量子硬件性能。量子模型 RMSE 略劣于经典基线，需在更大规模数据和真实硬件上进一步验证量子方法的潜力。
